# SCP_CB_CPP
A clone of the famous SCP Containment Breach game, but rewritten in C++ for better readability


# Build

```
cmake -B build
cmake --build build --config Release
```

# Rooms

Copy the original `GFX` folder of scpcb at the root of the project, then run:

```
scp_remake GFX/map
```

See docs/gfx.md.
